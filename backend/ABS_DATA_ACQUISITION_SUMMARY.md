
### Format Rules (All Implemented ✅)

| Field | Format | Example | Rule |
|-------|--------|---------|------|
| **Key** | SSC Code | "10570" | 4-5 digits, no state suffix |
| **population** | Integer | 15150 | Total persons |
| **medianAge** | Number | 35 | Years (decimal allowed) |
| **medianIncome** | Integer | 1635 | **ANNUAL AUD** (not weekly) |
| **employmentRate** | Decimal | 0.715 | **0.0-1.0** (not percentage) |
| **householdSize** | Number | 2.2 | Average persons per household |
| **datasetYear** | Integer | 2021 | Census year |

**Key Transformation:** Income converted weekly → annual (× 52)  
**Key Transformation:** Employment % → decimal (÷ 100)

## Critical Rules Implemented ✅

- ✅ **Keys are SSC codes** (not suburb names)
  - Example: "10570" not "Bondi|NSW"
  
- ✅ **No pipe delimiters**
  - Format: {"10570": {...}} not {"10570|NSW": {...}}
  
- ✅ **No state suffixes**
  - Format: "10570" not "10570_NSW"
  
- ✅ **Employment rate as decimal**
  - Format: 0.715 not 71.5 (division by 100 automatic)
  
- ✅ **Income as annual AUD**
  - Format: 1635 * 52 = 84,920 annual (conversion automatic)
  
- ✅ **No manual edits allowed**
  - All transformations via parser script

## Troubleshooting Reference

### Error: "Input file not found"
**Solution:** Verify `census_2021_ssc_export.csv` exists in backend directory

### Error: "Missing required fields"
**Solution:** Check CSV has exactly these headers (case-sensitive):
```
SSC_CODE_2021,Population,Median_Age,Median_Income,Employment_Rate,Household_Size
```

### Error: "Invalid numeric value in row N"
**Solution:** Check that column has only numbers (no text/symbols/commas except for formatting)

### Parser produces 0 records
**Solution:** Check CSV file is not empty and header row is present

### Output JSON file is empty
**Solution:** Verify parser ran to completion (look for "✅ Parser complete!" message)
